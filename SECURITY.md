# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, email **waey.official.mk@gmail.com** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 48 hours and provide a timeline for fix.

## Scope

This policy covers:

- The Waey frontend application (React + Vite)
- Supabase Edge Functions (`ai assistant`, `send contact`)
- Database schema and RLS policies

Out of scope: Third-party services (Supabase, Groq, Resend) — report those to their respective vendors.

## Disclosure

We follow coordinated disclosure. Once a fix is deployed, we will publish a security advisory in the GitHub Security tab.
